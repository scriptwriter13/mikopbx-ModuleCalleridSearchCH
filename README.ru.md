# О модуле
Модуль для MikoPBX, который при входящем звонке показывает имя звонящего из телефонного справочника
Швейцарии [tel.search.ch](https://tel.search.ch).

При каждом входящем звонке номер ищется в справочнике, и в имя CallerID подставляется строка вида
`Фамилия И. Город, Улица 1`. Номер может приходить как `044…`, `+4144…`, `004144…` или `4144…`.
Номера не из Швейцарии и номера, которых нет в справочнике, остаются без изменений,
поэтому имя, переданное провайдером, не теряется.

# Установка

**Обновление с версии 1.0:** сначала удалите старый модуль `CalleridSearchCH`. Идентификатор
модуля получил обязательный для MikoPBX префикс `Module`, поэтому установка поверх 1.0 оставит
оба модуля включёнными: два поиска на каждый входящий звонок и работающий старый скрипт.

1. Соберите архив модуля (см. ниже) или возьмите его на странице релизов.
2. В админ-панели MikoPBX откройте Модули → Установленные → Загрузить новый модуль и выберите zip-файл.
3. Включите модуль.
4. Откройте страницу модуля, вставьте ключ API и нажмите «Сохранить».

Требуется MikoPBX 2025.1.1 или новее.

# Ключ API

Ключ выдаётся на https://tel.search.ch/api/getkey, при умеренном использовании он бесплатен.
Без ключа справочник возвращает только имя, без города и улицы.

На странице модуля можно с помощью галочек выбрать, нужно ли отклонять анонимные звонки или звонки категории колл-центр.

# Конфиденциальность

Номер звонящего при каждом входящем швейцарском звонке передаётся в tel.search.ch по HTTPS.
Модуль ничего не хранит о звонках и не ведёт журнал имён и адресов.

# Решение проблем

- На весь запрос к справочнику отводится жёсткие 2 секунды. Если он не ответил, звонок
  продолжается с исходным CallerID.
- Сбои не замалчиваются и не рвут звонок: причина пишется в лог Asterisk через AGI verbose с
  префиксом `CalleridSearchCH:`. Отклонённый или исчерпанный ключ видно там же. Имена и адреса
  звонящих в лог не попадают.
- Имя не показывается: сначала посмотрите лог Asterisk, затем проверьте, что у номера есть
  публичная запись на tel.search.ch.
- Самопроверка без АТС и сети: `php tests/LookupTest.php`
